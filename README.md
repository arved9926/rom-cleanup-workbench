# Rom Cleanup Workbench

Finds duplicate ROM files in a folder by game name and deletes them on request. Requires Python 3.10 or newer, no additional packages. The program speaks English, German, Italian, Spanish, French and Japanese; the language is set in `redundanz_config.json`.

```bash
cd "Rom Cleanup Workbench"
python rom_cleanup_workbench.py "D:\Games"
```

The documentation is in [Rom Cleanup Workbench/README.md](<Rom Cleanup Workbench/README.md>).

**Deleted files do not go to the Recycle Bin.**
