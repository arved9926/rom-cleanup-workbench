# Rom Cleanup Workbench

Finds duplicate ROM files in a folder by game name and deletes them on request. Requires Python 3.10 or newer, no additional packages.

Findet doppelte ROM-Dateien in einem Ordner anhand des Spielnamens und löscht sie auf Wunsch. Benötigt Python 3.10 oder neuer, keine zusätzlichen Pakete.

| Folder | Language | Start |
| --- | --- | --- |
| [Rom Cleanup Workbench (englisch)](<Rom Cleanup Workbench (englisch)>) | English | `python duplicate_finder.py "D:\Games"` |
| [Rom Cleanup Workbench (deutsch)](<Rom Cleanup Workbench (deutsch)>) | Deutsch | `python redundanz_finder.py "D:\Spiele"` |

**Deleted files do not go to the Recycle Bin. / Gelöschte Dateien landen nicht im Papierkorb.**
